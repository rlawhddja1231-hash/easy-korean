# 영어·IT 용어를 쉬운 말로

답에 아래 왼쪽 말이 나오려 하면 오른쪽으로 바꾼다.
화면에 영어 그대로 떠서 사용자가 그 글자를 찾아 눌러야 하는 것만 영어로 두고, 괄호로 뜻을 붙인다.

| 영어·전문 용어 | 쉬운 말 |
|---|---|
| 파일/폴더 | 그대로 (이미 익숙함) |

| 다운로드 | 내려받기 |
| 업로드 | 올리기 |

| 업데이트 | 새 판으로 바꾸기 |
| 로그인 | 로그인(들어가기) |
| 계정 | 계정(아이디) |
| 설정 / Settings | 설정 |
| 메뉴 | 메뉴 |
| 버튼 | 버튼 |
| 탭 | 탭(위쪽 칸) |
| 링크 / URL | 링크(주소) |
| 브라우저 | 브라우저(인터넷 창) |

## 조금 더 어려운 것

| 영어·전문 용어 | 쉬운 말 |
|---|---|
| API | 프로그램끼리 서로 부탁하는 통로 |
| 토큰 | AI가 글을 세는 조각(글자 묶음) |
| 프롬프트 | AI에게 주는 지시 글 |
| 리포지토리 / 레포 | 깃허브에 올린 보관함 |
| 커밋 / 푸시 | 바뀐 것을 저장(커밋) / 깃허브에 올리기(푸시) |
| 릴리스 | 내려받을 수 있게 내놓은 판 |
| 플러그인 | 기능을 더해 주는 꾸러미 |
| 스킬 | Claude에게 가르치는 일하는 방법 꾸러미 |
| MCP 서버 | Claude가 바깥 프로그램과 연결되는 다리 |
| 터미널 / CLI | 명령어를 쳐서 쓰는 검은 창 |
| 경로(path) | 파일이 있는 자리(주소) |
| 디폴트 | 기본값(처음에 정해진 것) |
| 옵션 | 고를 수 있는 것 |
| 캐시 | 빨리 쓰려고 임시로 담아 둔 것 |
| 백업 | 복사본을 따로 저장해 두기 |
| 포맷 | ① 저장 방식(파일 종류) ② 디스크를 싹 비우기 |
| 싱크 / 동기화 | 두 곳을 똑같이 맞추기 |
| 렌더링 | 글·코드를 보이는 그림이나 화면으로 바꾸기 |
| 배포 | 남들이 쓰게 내놓기 |

## 말투 바꾸기 (번역투 → 우리말)

| 이런 말투 | 이렇게 |
|---|---|
| ~되어집니다 | ~됩니다 |
| ~에 의해 | ~가 / ~로 |
| ~를 가지고 있습니다 | ~가 있습니다 |
| ~하는 것이 가능합니다 | ~할 수 있습니다 |
| ~에 대해서 | ~는 / ~를 |
| ~라고 할 수 있습니다 | ~입니다 |
| 위와 같이 / 아래와 같이 | 이렇게 / 다음처럼 |
| 해당 파일 | 그 파일 |
| 진행하겠습니다 | 할게요 |
| 확인 부탁드립니다 | 봐 주세요 |

이 표에 없는 영어 낱말이 나오면, 중학생도 알 만한 가장 쉬운 우리말로 바꾸고, 한 번만 괄호로 원래 말을 적어 둔다.
